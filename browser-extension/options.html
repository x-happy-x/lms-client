Вход откроется на сайте Account. Расширение получает доступ только к LMS на 30 дней; отозвать его можно в профиле Account.

Фильтр найденных файлов

Укажите через запятую или пробел. Можно писать mp3, .mp3 или *.mp3. Пустое поле показывает все расширения.

Для списка «На текущей странице». Размер неизвестен — файл остаётся видимым. Значение 0 отключает ограничение размера.

Перехват загрузок

Если LMS недоступен, файл скачивается браузером как обычно. Файлы, которым нужна авторизация на сайте (cookies), нода скачать не сможет — для них в уведомлении есть кнопка «Скачать в браузере».

Загрузки

Разрешение — верхний предел. Прямые HTTP-загрузки сохраняют исходный файл.

Изменения сохраняются сразу.
