# Расширение LMS для Chromium

Расширение для Chrome, Edge, Яндекс Браузера и других браузеров на Chromium
(Manifest V3, Chrome 116+). Находит на страницах видео, файлы и magnet-ссылки
и отправляет их в LMS на роутере (`/api/ui`), чтобы скачала нода, а не браузер.

## Возможности

- **Скан страницы.** Находит `<video>`/`<audio>` с их источниками, `og:video`, ссылки
  на файлы (видео, архивы, образы, программы, документы, `.torrent`), ссылки с
  атрибутом `download` и magnet-ссылки. Страницы, которые догружаются (SPA,
  бесконечная лента), пересканируются. Количество находок видно на значке.
- **Потоки из сети.** Ловит HLS/DASH-манифесты (`.m3u8`, `.mpd`) и видео, которые
  грузит плеер через media, fetch/XHR, в том числе по ссылкам без расширения.
  Манифесты уходят в yt-dlp, полные медиафайлы — через HTTP. Известные сегменты
  потоков отбрасываются. История ресурсов страницы помогает найти уже загруженные
  файлы; учитываются iframe, открытые Shadow DOM и отложенные `data-src`.
- **Поиск через yt-dlp.** Иконка поиска рядом с названием страницы отдаёт страницу
  yt-dlp на ноде (без скачивания). Он знает сотни сайтов и находит встроенные видео на
  остальных: одно видео — с названием, длительностью и размером; плейлист, канал или
  страница с несколькими видео — карточками с превью и чипами выбора. Отправить можно выбранные ролики
  (каждый — отдельной загрузкой) или весь плейлист одной загрузкой. На сайтах с видео
  (YouTube, VK, Rutube…) поиск запускается сам при открытии окна. Нужен свежий lms-node.
- **Перехват загрузок.** Загрузка браузера нужного типа и размера отменяется и уходит
  в LMS. Типы и минимальный размер задаются в настройках. Файлы с самого LMS
  (скачивание на это устройство) не перехватываются. Если LMS недоступен, файл
  скачивается браузером как обычно.
- **Magnet-ссылки.** Клик по magnet-ссылке открывает загрузку в LMS, а не в торрент-клиенте.
- **Две вкладки.** «На текущей странице» показывает найденные файлы и одиночные
  видео yt-dlp; «Плейлист» — обложку и карточки роликов с постерами и длительностью.
  При первом открытии вкладки плейлиста поиск запускается автоматически.
  Доступны выбор всех/отдельных роликов чипами, скачивание выбранных, всего
  плейлиста или отдельного ролика. Если сайт не передал постер, показывается заглушка.
- **Popup.** У каждой находки можно выбрать способ загрузки (HTTP, yt-dlp,
  aria2c, торрент) и отправить. Карточки показывают постер, длительность,
  разрешение и размер, если страница или ответ сервера их сообщает. Находки
  обновляются, пока окно открыто, без сброса выбранного способа загрузки.
  Иконка обновления повторяет сканирование всех фреймов. Скачивание и обновление
  представлены SVG-кнопками с подписями для скринридера и подсказками при наведении.
  Общие параметры и поле «Добавить ссылку» свёрнуты в отдельные блоки.
  Вкладки работают с клавиатуры: стрелки, Home/End; чипы — Space.
- **Плейлист целиком.** Во вкладке «Плейлист» иконка «Скачать весь плейлист»
  отправляет его одной задачей, включая ролики за пределами показанного списка.
  Нода сохраняет ролики в отдельную папку `playlist-<id задания>`, с номерами
  в именах файлов. По-прежнему можно скачать только отмеченные ролики отдельными задачами.
- **Качество и формат.** В блоке «Параметры загрузки» доступны лучшее
  качество или верхний предел 360p–2160p, контейнер MP4/MKV и «Только аудио · M4A».
  yt-dlp выбирает доступное разрешение не выше заданного. HTTP/aria2c скачивают
  исходный файл; для обработки видео выберите yt-dlp. Для объединения потоков,
  смены контейнера и M4A на ноде нужен ffmpeg; контейнер меняется без принудительного
  перекодирования, поэтому несовместимые кодеки могут вызвать ошибку.
- **Место сохранения.** Выберите ноду и папку из подсказок либо введите подпапку
  (`video/courses`) или полный путь на ноде. Пустое поле использует папку ноды
  по умолчанию. Выбор сохраняется и для следующих загрузок, в том числе из
  контекстного меню. Если выбранная нода недоступна, расширение сообщает об этом;
  другую ноду автоматически не подставляет. При смене ноды поле папки очищается.
- **Контекстное меню:** «Скачать через LMS» для ссылки, видео или аудио, страницы и
  выделенного текста со ссылкой. `Alt+Shift+L` отправляет текущую страницу в yt-dlp.
- **Уведомления** об отправке. Если ноде нужна авторизация на сайте (cookies) и загрузка
  не пошла, в уведомлении есть кнопка «Скачать в браузере».

Для каждой ссылки расширение делает preflight на роутере и выбирает ноду: ту, что
рекомендует роутер, если она поддерживает нужный способ. Magnet и `.torrent` уходят как
`TORRENT`, сайты с видео и потоки как `YTDLP`, остальные файлы как `DIRECT`. Если нода
такой способ не поддерживает, берётся её рекомендация.

## Установка

1. Скачайте `lms-extension.zip` из
   [релизов](https://github.com/x-happy-x/lms-client/releases) (сборка CI при каждом
   изменении расширения в `master`) и распакуйте. Можно взять и эту папку из репозитория.
2. Откройте `chrome://extensions` (или `edge://extensions`, `browser://extensions`),
   включите «Режим разработчика» и нажмите «Загрузить распакованное».
3. Укажите папку. При первой установке откроются настройки расширения.
4. Подключите расширение к роутеру одним из способов:
   - откройте веб-интерфейс LMS → раздел «Расширение» → «Подключить к этому роутеру»
     (браузер спросит подтверждение);
   - или в настройках расширения введите адрес LMS (например `192.168.1.1:8082` или
     `https://lms.local`) и нажмите «Проверить связь».

В разделе «Расширение» веб-интерфейса та же инструкция и статус: установлено ли
расширение и подключено ли к этому роутеру.

Если LMS доступен через прокси с паролем, укажите в настройках логин и пароль
(HTTP Basic).

В **0.6.0** появился вход через Account: в настройках укажите адрес Account
и нажмите «Войти». Авторизация откроется на сайте Account; расширение
получает токен только для LMS на 30 дней. Текущий аккаунт и выход доступны
также в popup. Нужны обновлённые Account и роутер с включённой авторизацией —
[настройка](../docs/account-auth.md). До включения на сервере настройки
показывают соответствующее сообщение.

Новый публичный ключ в manifest фиксирует ID расширения. Если старая
распакованная версия имела другой ID, загрузите новую папку, укажите адреса
и войдите заново. В дальнейшем ID одинаков при переносе папки.

Скачивание на устройство, торренты и ограничение скорости требуют свежих lms-client
и lms-node.

Качество, аудио/контейнер и скачивание целого плейлиста с отдельной папкой требуют
обновлений **LMS-11** (lms-node) и **LMSC-7** (lms-client/расширение 0.4.0).
Порядок обновления: нода → клиент роутера → расширение. Роутер автоматически
применяет миграцию SQLite `005_add_ytdlp_options.sql`; параметры сохраняются при
перезапуске, паузе и повторе задания. Старые ноды определяются по preflight,
без поддержки параметров расширение предложит обновление вместо скачивания с
проигнорированными настройками.

## Разработка

```bash
npm test          # node --test: разбор ссылок, правила перехвата, выбор ноды
npm run icons     # перегенерировать icons/*.png
```

Внешних зависимостей нет. Логика без браузерных API лежит в `lib/` и покрыта тестами:

- `links.js` — классификация ссылок;
- `intercept.js` — что перехватывать;
- `router.js` — клиент `/api/ui`.

Поиск не гарантирует скачивание любого плеера: закрытые Shadow DOM, DRM и
потоки с нестандартными сегментами могут потребовать поиска страницы через
yt-dlp. Cookies браузера на ноду не передаются; ссылки, требующие текущей
браузерной сессии, могут быть недоступны ноде. Прогресс загрузки и готовые
файлы по-прежнему доступны в веб-интерфейсе LMS.

`popup.html?tab=<id>` открывает popup для заданной вкладки как обычную страницу. Это
удобно для отладки.
