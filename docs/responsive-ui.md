# Адаптивный интерфейс LMS (LMSC-16)

Веб-клиент использует общие токены поверхностей, цвета, скругления и действий
для обеих тем. Карточки файлов, плейлисты, формы и навигация остаются в одной
дизайн-системе. Второстепенные параметры списка находятся в раскрываемом блоке
«Фильтры»; выбранные параметры сохраняются существующим механизмом preferences.

Навигация: от 1121 px — боковая панель; 641–1120 px — компактная панель иконок;
до 640 px — основные разделы и кнопка «Ещё» с полным списком. При добавлении
раздела в `App.tsx` поле `primary` включает его в нижнюю панель. Файлы подключены как основной раздел вместо нод; ноды доступны в «Ещё» и на
боковой панели. HomeNet/VPN следует подключать без primary, в «Ещё».

Диалоги ограничивают фокус, закрываются Escape и возвращают фокус на действие,
которое их открыло. Фильтры закрываются Escape и при уходе фокуса. Статусы
переключаются стрелками, Home/End. Иконки — SVG, у компактного добавления есть
доступная подпись. Учитываются safe-area, высота окна и reduced-motion.

Проверка: TypeScript noEmit, сборка UI, нейтральные Edge-фикстуры на 390/768/1440 px
в обеих темах. Проверены отсутствие горизонтального переполнения, раскрытие
фильтров, размер SVG добавления, «Ещё», переход к настройкам, Tab/Escape и возврат
фокуса, окно добавления. Повторно проверены раскрытие стопок, выбранные задания
с разными статусами, метаданные и отправка выбранных роликов с общим playlist id.


После интеграции LMSC-18 проверен реальный FilesPage внутри общего shell:
выбор ноды/диска, папки/хлебные крошки/поиск, просмотр изображения, создание и
переименование папки, удаление только после подтверждения, ошибка/повтор и
read-only роль viewer. Проверка 390/768/1440 px, обе темы; footer диалога остаётся
видимым и при уменьшении viewport до 480 px по высоте (имитация места клавиатуры).
Проверки используют синтетический локальный API, реальные файлы не меняются.
