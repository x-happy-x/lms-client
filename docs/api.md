# Router UI API (MVP draft)

## Jobs

- `POST /api/ui/jobs`
- `GET /api/ui/jobs?active=true`
- `GET /api/ui/jobs/{id}`
- `POST /api/ui/jobs/{id}/cancel`

## Nodes

- `GET /api/ui/nodes`
- `POST /api/ui/nodes`

## Profiles

- `GET /api/ui/profiles`
- `POST /api/ui/profiles`

## Health

- `GET /api/ui/system/health`
- `GET /api/ui/system/version`

All request/response schemas will be finalized during implementation.
